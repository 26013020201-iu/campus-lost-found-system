 # Campus Lost & Found System

## Introduction
The Campus Lost & Found System is a Python-based application that helps college students report and recover lost items on campus.

## Features
1. Report Lost Items
2. Report Found Items
3. View All Reported Items
4. Search Items
5. Mark Items as Returned
6. Store Data Using JSON

## Technologies Used
- Python 3
- JSON
- File Handling

## Project Files
- main.py - Main application
- campus_items.json - Data storage
- README.md - Project documentation

## How to Run
1. Install Python 3.
2. Download the project.
3. Open the project folder.
4. Run: python main.py

## Project Objective
To make it easier for students to find their lost belongings within the college campus.
